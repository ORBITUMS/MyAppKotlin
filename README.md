В общем это моё первое приложение на телфон, написанное на котлине

сутm приложение - это добавить на него фичи, для обучения моего мастерства в котоине.

## 🛠️ Технологический стек

*   **Language:** Kotlin
*   **UI Framework:** Jetpack Compose
*   **Design System:** Material Design 3
*   **Navigation:** Jetpack Navigation Component

## 🏗️ Структура кода

Основная логика приложения сосредоточена в файле `MainActivity.kt`:

*   `AppNavigation` — управляет переходами между экранами (`menu` и `second`).
*   `MenuScreen` — стартовый экран с красивым градиентным фоном и кнопкой старта.
*   `SecondScreen` — игровой экран, где генерируются случайные комбинации цветов и проверяются ответы пользователя.
*   `SmallColorButton` — переиспользуемый компонент круглой кнопки для выбора цвета.
