# 🎰 My App — первое приложение на Kotlin

Это моё первое мобильное приложение, написанное на Kotlin с использованием Jetpack Compose.

Изначально проект задумывался как **тренажёр для прокачки скиллов** в Kotlin, но постепенно вырос в полноценную мини-игру в стиле казино. Сейчас это небольшая игровая платформа со слотами, фриспинами, апгрейдером ставок, банком, кардингом и промокодами.

Проект живой — я продолжаю добавлять новые фичи по мере изучения Kotlin, Jetpack Compose и корутин.

---

## 🎮 Что уже есть в игре

### 🏠 Главное меню
- Премиальная тёмная тема с золотыми и неоновыми акцентами.
- Верхняя панель с плавно анимированными счётчиками баланса и фриспинов.
- Сетка тематических кнопок с эмодзи: слоты, фриспины, банк, промокоды, донат, мультиплеер, цвета, пополнение и инфо.

### 🎰 Слот-машина
- Три барабана с эмодзи-символами (7️⃣ 💎 🔔 🍉 🍇 🍋 🍒) и индивидуальными множителями.
- Подсветка обводки при 2 совпадениях и **полноэкранная подсветка** при 3 в ряд — цвет берётся из неоновой палитры выпавшего эмодзи.
- Автопрокрут (1/3 кнопки) + обычный спин (2/3 кнопки).
- Кнопки изменения ставки: -1000, -100, -10, +10, +100, +1000.
- Реклама на 15 секунд за **+3 фриспина** (с секретной пасхалкой для мгновенного пропуска).

### 🎁 Фриспины
- Три типа колёс: обычное, богатое, бедное.
- Смена колеса только при попадании на специальный сектор смены (💎 / 🗑 / 🎰).
- Бонусный сектор «+8 🎁» даёт +8 фриспинов.
- Автопрокрут с возможностью остановки прямо во время вращения.
- Список промокодов **в одном месте** — легко добавлять новые.

### ⚡ Апгрейдер ставки
- Колесо с настраиваемым шансом выигрыша (1%–95%).
- Пресеты-тумблеры: `x3`, `x4`, `100x`, `70%`, `50%`, `10%`.
- Честный целочисленный расчёт выигрыша без float.
- При касании поля «Выигрыш» пресет сбрасывается — можно вводить вручную.

### 🏦 Банк
- Кредиты до 10 000 $ с подписью (можно нарисовать пальцем на Canvas).
- Долг **удваивается каждую минуту** (включая офлайн-время).
- Потолок долга — 1 триллион.
- Минималистичная кнопка «Погасить кредит».
- Отдельный экран с PIN-кодом (секретный код прячется в ТГК проекта).

### 💳 Кардинг (BalanceScreen)
- Поиск случайных карточек по локациям (33% шанс).
- Авторизация по 16-значному номеру, сроку и CVC.
- Переводы с карты в игру с шансом фрод-блокировки.
- Сохранение найденной карты в SharedPreferences.

### 🎫 Промокоды
- Все промокоды хранятся в одном списке `PROMO_CODES` — добавление нового занимает одну строку.
- Поддержка денежных и спиновых бонусов одновременно.
- Флаг `oneTime` — одноразовый или многоразовый.
- Секретные коды: `5252` (режим разработчика) и `666` (полный сброс).

## 🛠️ Технологический стек

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Design System:** Material Design 3
- **Navigation:** Jetpack Navigation Component
- **State:** `remember`, `mutableStateOf`, `Animatable`, `AnimatedContent`, `animateColorAsState`
- **Storage:** `SharedPreferences` (единый ключ `casino_prefs` для всех экранов)
- **Async:** Kotlin Coroutines + `LaunchedEffect`, `rememberCoroutineScope`
- **Graphics:** Canvas, Path, Brush, custom drawing

## 🏗️ Структура кода

Основная логика разбита по экранам, каждый экран — отдельная `@Composable`-функция в своём файле:

| Файл | Назначение |
|---|---|
| `MainActivity.kt` | `AppNavigation` + `MenuScreen` — точка входа, навигация и главное меню с промокодами. |
| `SecondScreen.kt` | Мини-игра «Эффект Струпа» — тренажёр цветов. |
| `ThirdScreen.kt` | Слот-машина с автопрокрутом, подсветкой и рекламой за фриспины. |
| `FourthScreen.kt` | Апгрейдер ставки с колесом и пресетами. |
| `FreeSpinsScreen.kt` | Фриспины с тремя колёсами и лентой выигрышей. |
| `Bank.kt` | Банк с кредитами, подписью и PIN-кодом. |
| `BalanceScreen.kt` | Кардинг — поиск, авторизация и переводы с карточек. |

### Верхняя панель `TopBarCasino`

Универсальный компонент, повторяющийся на всех экранах: слева — логотип `🎰 Mysor`, справа — чипы с плавно анимированными значениями (баланс, фриспины, макс. куш). Реализован через `AnimatedContent` с вертикальным слайдом.

### Глобальные счётчики

Все экраны читают и пишут одни и те же ключи в `SharedPreferences("casino_prefs")`:

- `balance` — баланс игрока (по умолчанию 100).
- `free_spins` — количество фриспинов (по умолчанию 0).
- `max_win` — максимальный куш за всё время.
- `bank_banned_until` — таймер блокировки банка.
- `loan_approved`, `loan_debt`, `loan_borrower`, `loan_last_time` — данные кредита.
- `saved_card_*` — сохранённая найденная карта.
- `last_bonus_time` — кулдаун утешительного бонуса.
- `promo_<код>_used` — флаги использования промокодов.

Это позволяет держать баланс и фриспины синхронными между экранами: заработал в слотах — увидел в главном меню, взял кредит — потратил на апгрейдере.

## 🎨 Дизайн

- **Тёмная тема** с вертикальным градиентом `#111827 → #1F2937` (главное меню, банк) и `#1A1A2E → #16213E` (слоты).
- **Золотые обводки** `#FFD700` и градиент `#FFE259 → #FFA751` для премиальных карточек.
- **Неоновые акценты** для кнопок: голубой, оранжевый, зелёный, фиолетовый, красный.
- **Плавные анимации:** `AnimatedContent`, `animateColorAsState`, `animateDpAsState`, `animateFloatAsState`, кастомные корутины.
- **Эмодзи-иконки** на всех кнопках и заголовках.
